# سهرة ألعاب (Game Night)

منصة ألعاب جماعية في المتصفح: افتح غرفة، أرسل الرابط، والعبوا من جوالاتكم فورًا.
**الإصدار 0.1 — المرحلة الأولى:** المنصة كاملة + لعبة إكس أو أونلاين حقيقية. باقي الألعاب تظهر بعلامة «قريبًا».

---

## النشر على الإنترنت (حوالي 15 دقيقة، مجانًا)

ستحتاج حسابين مجانيين: **GitHub** (لحفظ الملفات) و **Render** (لتشغيل الموقع). لا تحتاج أي مفاتيح سرية ولا قاعدة بيانات.

### الخطوة 1: ارفع الملفات إلى GitHub
1. افتح github.com واضغط **Sign up** وأنشئ حسابًا.
2. بعد الدخول اضغط زر **+** أعلى الصفحة ثم **New repository**.
3. في **Repository name** اكتب `game-night`، اختر **Private** أو **Public** (أي واحد)، واضغط **Create repository**.
4. في الصفحة التالية اضغط الرابط **uploading an existing file**.
5. فك ضغط ملف `game-night.zip` على جهازك، وافتح المجلد، ثم **حدد كل ما بداخله** (المجلدات والملفات) واسحبه إلى صفحة GitHub.
   - تأكد أن `package.json` يظهر في أعلى القائمة مباشرة، وليس داخل مجلد اسمه game-night.
6. انتظر انتهاء الرفع، ثم اضغط **Commit changes** أسفل الصفحة.

### الخطوة 2: شغّل الموقع على Render
1. افتح render.com واضغط **Get Started**، واختر **GitHub** لتسجيل الدخول (أسهل طريقة).
2. من لوحة التحكم اضغط **New +** ثم **Web Service**.
3. اختر مستودع `game-night` (إذا لم يظهر: اضغط **Configure account** واسمح لـ Render بالوصول إليه).
4. املأ الإعدادات هكذا:
   | الحقل | القيمة |
   |---|---|
   | Name | `game-night` (أو أي اسم، سيصبح جزءًا من الرابط) |
   | Language / Runtime | `Node` |
   | Branch | `main` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |
5. اضغط **Deploy Web Service** وانتظر حتى تظهر كلمة **Live** (2–4 دقائق).
6. رابط موقعك يظهر أعلى الصفحة، مثل: `https://game-night-xxxx.onrender.com`

> اختياري: في **Settings → Health Check Path** اكتب `/health`.

### الخطوة 3: جرّب بجوالين على شبكتين مختلفتين
1. جوال 1 على **بيانات الجوال** (أطفئ الواي فاي)، وجوال 2 على **الواي فاي**.
2. على جوال 1: افتح الرابط ← **أنشئ غرفة** ← اكتب اسمك ← **أنشئ الغرفة**.
3. اضغط **واتساب** أو **شارك الدعوة** وأرسل الرابط لجوال 2.
4. على جوال 2: افتح الرابط ← اكتب اسمك ← **ادخل الغرفة**.
5. على جوال 1: **ابدأ اللعب**. العبوا جولة كاملة وتأكد أن كل حركة تظهر عند الآخر فورًا.
6. جرّب أيضًا: حدّث الصفحة على أحد الجوالين أثناء اللعب، يجب أن يرجع لنفس مكانه.

### الخطوة 4: شارك مع أصحابك
أرسل رابط الموقع، أو أنشئ غرفة وأرسل رابط الدعوة مباشرة (`.../r/رمز_الغرفة`).

### الخطوة 5: تحديث الموقع لاحقًا (عند إضافة ألعاب جديدة)
1. في صفحة المستودع على GitHub اضغط **Add file → Upload files**.
2. اسحب الملفات الجديدة أو المعدّلة (بنفس أماكنها في المجلدات) واضغط **Commit changes**.
3. Render يلاحظ التغيير ويعيد النشر تلقائيًا خلال دقائق. الغرف المفتوحة وقتها ستُغلق، فحدّث في وقت لا يلعب فيه أحد.

## تحويله إلى تطبيق على الجوال

الموقع مجهّز كتطبيق قابل للتثبيت (أيقونة على الشاشة، يفتح بملء الشاشة بلا شريط عنوان). أصحابك **لا يحتاجون أي تثبيت** ليلعبوا؛ رابط الدعوة يكفي.

### الطريقة 1 (الأسهل): التثبيت من المتصفح — بلا APK
- **أندرويد (Chrome):** افتح الموقع ← اضغط زر **«ثبّت التطبيق على جوالك»** في الصفحة الرئيسية، أو من قائمة ⋮ اختر **Install app / تثبيت التطبيق**.
- **آيفون (Safari):** افتح الموقع ← زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.

### الطريقة 2: ملف APK لأندرويد (بعد نشر الموقع)
1. افتح **pwabuilder.com** والصق رابط موقعك على Render، ثم اضغط **Start**.
2. اضغط **Package For Stores** ثم **Generate Package** تحت **Android**.
3. اترك الإعدادات كما هي (Signing key: **New**)، واضغط **Download Package**.
4. فك ضغط الملف الناتج. ستجد:
   - ملف **.apk**: هذا هو التطبيق، انقله لجوالك وافتحه للتثبيت (سيطلب أندرويد السماح بالتثبيت من مصدر خارجي).
   - ملف **.aab**: للرفع على Google Play فقط إن أردت لاحقًا (حساب مطوّر برسوم 25 دولار مرة واحدة).
   - **signing.keystore** و **signing-key-info.txt**: احفظهما في مكان آمن؛ تحتاجهما لأي تحديث للتطبيق.
   - **assetlinks.json**: ارفعه للموقع (الخطوة التالية).
5. رفع assetlinks.json (حتى يفتح التطبيق بلا شريط عنوان):
   - في مستودع GitHub اضغط **Add file → Create new file**.
   - في خانة الاسم اكتب بالضبط: `public/.well-known/assetlinks.json`
   - افتح ملف assetlinks.json على جهازك بالمفكرة، انسخ محتواه والصقه، ثم **Commit changes**.
   - انتظر إعادة النشر على Render (دقائق)، وتأكد بفتح: `رابط-موقعك/.well-known/assetlinks.json`

> التطبيق يعرض الموقع المنشور نفسه، لذلك أي تحديث ترفعه على GitHub يظهر في التطبيق تلقائيًا دون بناء APK جديد.

## ماذا تعني الخطة المجانية في Render؟
- إذا لم يزر أحد الموقع **15 دقيقة**، يدخل في وضع النوم. أول زيارة بعدها تأخذ **حوالي دقيقة** حتى يستيقظ. افتح الموقع قبل السهرة بدقيقة.
- أثناء اللعب الاتصال المستمر يبقي الموقع مستيقظًا.
- 750 ساعة تشغيل مجانية شهريًا لكل حساب (وقت النوم لا يُحسب) — تكفي لموقع واحد يعمل طوال الشهر.
- الغرف تُحفظ في ذاكرة الخادم فقط، وتُمسح عند النوم أو إعادة النشر. هذا مقصود: الغرف مؤقتة بطبيعتها، ولا توجد بيانات شخصية محفوظة.
- لو أردت لاحقًا موقعًا لا ينام: خطة Render المدفوعة (Starter) — تحقق من سعرها الحالي في موقعهم.

## للمطوّرين: البنية التقنية

**الاختيار:** Node.js + Express + Socket.IO على خادم واحد.
- الخادم هو المرجع الوحيد لكل حركة (يتحقق من الدور والخانة ويمنع التكرار)، فلا يستطيع أي لاعب التلاعب بالنتيجة من متصفحه.
- كل لاعب يستلم نسخة خاصة به من الحالة (`view(state, playerId)`)، وهذا جاهز للألعاب ذات المعلومات السرية مثل «مين الجاسوس؟».
- لا توجد مفاتيح سرية في الواجهة ولا في المشروع أصلًا.
- لم نستخدم Supabase/Firebase: كانا سيتطلبان قاعدة بيانات وسياسات أمان ودوال خادم منفصلة وإعداد مفاتيح، بينما خادم Socket.IO واحد يحقق كل المتطلبات بخطوة نشر واحدة.

```
server/
  index.js          الخادم والاتصال اللحظي
  rooms.js          الغرف، اللاعبون، الاستضافة، الانقطاع، التنظيف، النقاط
  games/index.js    سجل الألعاب
  games/tictactoe.js قواعد إكس أو (منطق خالص، بلا شبكة)
shared/catalog.js   بيانات الألعاب (مشتركة بين الخادم والواجهة)
public/
  index.html, css/, fonts/ (خطوط محلية)
  js/app.js         التنقل والشريط العلوي
  js/net.js         الاتصال بالخادم والجلسة
  js/i18n.js        النصوص العربية والإنجليزية
  js/screens/       الرئيسية، الإنشاء/الدخول، الغرفة والنتائج
  js/games/         واجهة كل لعبة
tests/              اختبارات المنطق والغرف واللعب الجماعي عبر الشبكة
tools/e2e_two_players.py  اختبار متصفحين مستقلين (Playwright)
```

**واجهة اللعبة على الخادم:** `setup(roster, prev)`، `action(state, playerId, action)`، `outcome(state)`، `playerLeft(state, playerId)`، `view(state, playerId)`.

**قواعد الغرفة:** رمز من 5 خانات بلا حروف ملتبسة؛ مهلة عودة المنقطع 60 ثانية ثم يخرج (ويخسر الجولة إن كان يلعب)؛ تنتقل الاستضافة بعد 20 ثانية من انقطاع المضيف أو فورًا عند مغادرته؛ تُحذف الغرفة الفارغة بعد 10 دقائق والخاملة بعد 3 ساعات.

### التشغيل على جهازك (اختياري)
```
npm install
npm start          # http://localhost:3000
npm test           # 31 اختبارًا
```
